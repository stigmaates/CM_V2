# Pilot onboarding checklist

This checklist is for the first manually supported club launches.

## Before setup

- Confirm club name and owner contact.
- Confirm LANGAME is used and API access is available.
- Confirm Telegram channel/chat strategy.
- Confirm who will receive КБ transfer notifications.
- Agree pilot dates and success metrics.

## Technical setup

- Create owner account.
- Create club record.
- Add LANGAME API key and secret.
- Add Telegram admin chat id for КБ notifications.
- Configure social links and map links if available.
- Run initial guest sync.
- Run initial session sync.
- Run initial operation sync.
- Check owner dashboard numbers.
- Check CRM analytics numbers.

## Guest flow

- Open guest login page.
- Start Telegram auth flow.
- Confirm login token.
- Open guest dashboard.
- Check missions.
- Check token balance.
- Spin wheel if enabled.
- Check КБ balance and redeem flow.

## Owner flow

- Review dashboard.
- Review CRM analytics.
- Create a test segment.
- Preview segment recipient count.
- Create a test mission.
- Configure wheel settings.
- Add wheel prizes.
- Confirm active prize probability sum.
- Create a test mailing to a small safe segment.

## Launch decision

- No critical sync errors.
- Guest login works.
- Owner dashboard opens without errors.
- Telegram admin notifications work.
- Backup is enabled.
- Support contact is known to the owner.

## Pilot success metrics

- Number of Telegram-authorized guests.
- Number of completed missions.
- Number of wheel spins.
- Number of КБ redemptions.
- Repeat visits during pilot period.
- Owner feedback score.
