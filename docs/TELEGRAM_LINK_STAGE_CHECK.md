# Проверка привязки Telegram при разных номерах

Изменение проверяем на стейдже. Перенос в прод — после отдельного подтверждения.

## Подготовка

- Применить `venv/bin/python scripts/migrate.py` (миграция `0024_telegram_link_requests`).
- Перезапустить `clubmodule-stage-bot.service`, `clubmodule-stage-admin-bot.service` и web.
- У тестового клуба задать собственный `cm_bonus_admin_chat_id` с тестовым чатом.
- Добавить админского бота в этот чат с правами администратора; проверяющий должен быть владельцем или администратором Telegram-чата.
- Использовать тестового гостя, ещё не связанного с Telegram, с отличающимся номером LG.

## Сценарии

1. Открыть страницу входа конкретного клуба, перейти по ссылке в личный чат гостевого бота и отправить свой контакт.
2. Если контакт не найден, проверить две кнопки: «Мой номер Telegram не совпадает с номером в LG» и «Это точно мой номер».
3. Вторая кнопка показывает «Обратитесь к администратору для помощи с этой проблемой».
4. Первая кнопка запрашивает номер LG. Форматы `8…`, `7…`, десять цифр должны находить того же гостя только внутри выбранного клуба.
5. Бот показывает найденное имя и номер. «Нет» завершает сценарий сообщением об обращении к администратору.
6. «Да» создаёт заявку. Вход до одобрения недоступен. Администратор получает номер заявки и ID аккаунта LG, проверяет аккаунт и личность гостя, сверяет заявку на его телефоне.
7. Отклонение не меняет `guests.telegram_id`. Подтверждение связывает Telegram с гостем; номер LG остаётся прежним.
8. После подтверждения открыть новую ссылку входа. Бот должен подтвердить вход без повторного ввода номера LG. Приветственная награда использует существующую защиту от повторного начисления.
9. Повторное нажатие админской кнопки не меняет результат. Чужой чат и обычный участник чата не могут подтвердить заявку.
10. Аккаунт, уже связанный с другим Telegram, не перепривязывается. Один Telegram не связывается с двумя гостями одного клуба.

## Ожидание и ошибки

- Заявка хранится в базе, действует 24 часа и переживает перезапуск ботов.
- Ссылка входа действует 10 минут; после одобрения используется новая ссылка независимо от срока старой.
- Незавершённый диалог ввода номера после перезапуска нужно начать заново.
- Повторная активная заявка одного Telegram в клубе запрещена. Лимит — три заявки за 24 часа, включая ошибки доставки.
- Поиск по введённому номеру ограничен пятью попытками в час на Telegram ID в процессе бота.
- Если отправка заявки в Telegram не удалась, бот сообщает об этом; администратор не сможет одобрить заявку со статусом `send_failed`.
- Если личное уведомление о решении не доставлено, сохранённая привязка всё равно работает при новом входе.
- ФИО, телефоны и Telegram ID в админское уведомление не включаются. Номера пары сохраняются в таблице заявок, а автор решения и время — в записи рассмотренной заявки.

Автотесты используют подменённые базу и Telegram API. Реальная доставка и вход двумя ботами проверяются этим сценарием на стейдже.
